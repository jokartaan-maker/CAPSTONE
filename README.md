# CAPSTONE

## Graduation Projects Management System

A web-based platform designed to organize and manage the graduation project lifecycle within a university.

### Main Features
- User Authentication and Role Management
- Graduation Project Ideas Management
- Student Team Management
- Supervisor Assignment
- Project Proposal Submission and Review
- Project Milestones and Progress Tracking
- Deliverables and File Management
- Notifications and Status Updates
- Project Evaluation and Reports
